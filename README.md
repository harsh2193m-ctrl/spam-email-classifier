# Spam Email Classifier

## Internship Project
A machine-learning model that classifies messages as Spam or Ham (not spam) using TF-IDF features and Multinomial Naive Bayes.

## Features
- Text preprocessing
- TF-IDF vectorization
- Multinomial Naive Bayes classification
- Accuracy and classification report
- Prediction for a new message

## How to run
```bash
pip install -r requirements.txt
python spam_classifier.py
```

## Technologies
Python, Pandas, Scikit-learn, NLP, TF-IDF, Naive Bayes
